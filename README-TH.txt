เว็บเซอร์ไพรส์ครบรอบ 1 เดือน

วิธีเปิดง่ายที่สุด
1. แตกไฟล์ ZIP ทั้งหมดก่อน
2. เปิดไฟล์ index.html ด้วย Chrome หรือ Edge
3. กด “เปิดเซอร์ไพรส์ของเธอ” เพื่อเริ่มเว็บและเพลง
ไม่ต้องติดตั้ง Python, Node.js หรือโปรแกรมเพิ่มเติม

สิ่งที่มี
- หน้าเซอร์ไพรส์และหน้าครบรอบ 1 เดือน
- รูปคู่ทั้ง 7 รูป กดขยายและเลื่อนดูได้
- จดหมายหวานและเอฟเฟกต์หัวใจ
- เพลง love.mp3 วนซ้ำ พร้อมเล่น/พักเพลง ปุ่ม + / − และแถบเสียง
- รองรับมือถือและคอมพิวเตอร์

ปรับข้อความ: เปิด index.html ด้วย Notepad หรือ VS Code
ปรับคำบรรยายรูป: แก้รายการ photos ใน script.js
เปลี่ยนเพลง: วางไฟล์ชื่อ love.mp3 ใน assets แทนไฟล์เดิม
เปลี่ยนรูป: วางรูปชื่อเดิมใน assets หรือแก้ชื่อใน HTML และ script.js
สีและหน้าตา: แก้ style.css

นำขึ้นเว็บ
อัปโหลด index.html, style.css, script.js และโฟลเดอร์ assets ทั้งชุด
ใช้โฮสต์ Static HTML ได้ ไม่ต้องใช้คำสั่ง Build
หากใช้ Vercel เลือก Framework Preset: Other และไม่มี Build Command
ตั้ง Root/Output ให้เป็นโฟลเดอร์ที่มี index.html

หมายเหตุ
เพลงจะเริ่มเมื่อผู้ชมกดปุ่ม เนื่องจากเบราว์เซอร์จำกัดเสียงอัตโนมัติ
ฟอนต์สวยงามโหลดจาก Google Fonts เมื่อออนไลน์ หากออฟไลน์จะใช้ฟอนต์ในเครื่อง
บางเบราว์เซอร์บน iPhone อาจให้ควบคุมความดังด้วยปุ่มเสียงของเครื่อง
ไฟล์เป็น HTML + CSS + JavaScript ไม่มี Python และไม่มีฐานข้อมูล

อัปเดตเวอร์ชัน 2
เรียกแฟนว่า “เบ้บ” และแทนตัวผู้เขียนว่า “เค้า”
หน้าโมเมนต์แสดงทีละรูปพร้อมหนึ่งคำพูด มีทั้งหมด 7 โมเมนต์
ใช้ปุ่มก่อนหน้า/ถัดไป จุดเลือกภาพ ปุ่มลูกศรคีย์บอร์ด หรือปัดบนรูปในมือถือ
รูปสุดท้ายกดต่อเพื่ออ่านจดหมายได้ รูปในหน้าจดหมายเปลี่ยนเป็นรูปคู่กอดกัน
